# MCP Brief – 2026-07-30

## Idea Name
MCP Tool Guardian

## Repo
mcp-tool-guardian-20260730

## Problem
AI agents fail silently or cascade into wrong decisions because tool/MCP outputs are unvalidated, can contain secrets, or hide injection patterns. There is no standard lightweight reliability layer that agents themselves can call.

## Solution
A pure-computation MCP server that gives agents five tools:
1. validate_against_schema
2. sanitize_tool_output
3. score_reliability
4. detect_suspicious_patterns
5. create_audit_entry

## Why Type A (preferred)
- Local only (jsonschema + regex + heuristics)
- Zero ongoing API cost
- Fast
- High perceived value for safety-conscious founders

## Target User
- Indie hackers & startups building agent products
- Teams that care about AI accountability (Prevalid audience)
- Developers who already use Claude Desktop / Cursor / Windsurf

## Differentiation
Most MCP servers *expose* capabilities. This one *protects* the agent while using any other capability.

## Monetization Path
Free open-source core → paid hosted version with persistent audit dashboard and team sharing.

## Validation Signals (from research)
- Multiple 2026 reports on MCP security crisis and tool poisoning
- Schema validation is already recommended in official MCP docs
- Agent reliability / observability is a rising pain point
- Prevalid’s own mission aligns perfectly
